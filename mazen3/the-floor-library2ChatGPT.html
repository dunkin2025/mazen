METHOD

Modular Architecture

01

Silence Bias Engine

Each preset carries a defined silence percentage (72–96%). The engine uses this value as an event suppression probability. Silence is structurally encoded, not manually edited.

02

Texture Generator

Web Audio API nodes (noise buffer, filters, gain envelopes) generate spectral texture in-browser. No audio files are loaded. Each preset configures filter frequency and energy profile.

03

Event Scheduler

Events are scheduled probabilistically using bias-weighted random intervals. Short-attack, long-release. Silence is the default; events only mark boundaries.

04

Validity Principle

No performance data. No achievement layer. Zero events is a valid, complete session. The library’s job is to create the boundary.
