Silence Index — How to read the bar on each card

The percentage shown is the silence bias — the proportion of a given interval occupied by structured absence rather than tonal events. It is a design parameter, not a quality score. Higher is not better. Each field is calibrated for a specific environment type: a lobby or retail space typically runs 65–80%; a focused work session 82–88%; a ritual or reset session 90–94%. The bar shows where on that spectrum each preset sits. It does not indicate how much you will hear — it indicates how the field is architecturally weighted.

Method Modular breakdown of the soundscape architecture
01 · Silence Bias Engine
Each preset carries a defined silence percentage (72–96%). The engine uses this value as an event suppression probability. No events are generated during silent intervals — silence is structurally encoded, not manually edited.
02 · Texture Generator
Web Audio API nodes (oscillators, filters, gain envelopes) generate spectral texture in-browser. No audio files are loaded. Each preset configures filter frequency, noise color, gain envelope shape, and event interval range.
03 · Event Scheduler
Events (texture bursts, tonal moments) are scheduled probabilistically using bias-weighted random intervals. At 94% silence, fewer than 4 events occur per minute on average. Events are short-attack, long-release.
04 · Preset Schema
Each soundscape is a configuration object defining: filter type & frequency, noise base color, event rate, silence bias, gain envelope, philosophy concept, and visual accent color. Not a static audio file — a behavioral description.
05 · Plan Gate
Free-tier presets run without restriction. Pro presets check plan state before allowing audio engine initialization. The gate is client-side for demo; production gates at session token level. Locked state shows upgrade path inline.
06 · Canvas Visualizer
Each card renders a live miniature canvas reflecting the preset's event density and silence profile. The main waveform bar animates from audio data when playing. Visual output is derivative of the audio state — not decorative.
07 · Quick Mix
Quick Mix is an in-browser selector that loads a preset directly into the player without navigating the full library. It respects plan gating. Philosophy-curated chips map to specific preset configs — not random generation.
08 · Validity Principle
Sessions generate no performance data. Event count is not shown as achievement. Zero events is a valid, complete session. The library's job is to create the boundary — what happens inside belongs to the listener.
