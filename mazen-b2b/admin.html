Google Sheets intake review

This GitHub migration uses Google Sheets as the operator inbox. Open your sheet to review what prospects wanted, when they submitted, and what the brief engine recommended. The public intake page remains unchanged in look and feel; only the storage layer moved from Cloudflare D1 to Apps Script + Sheets.

Recommended operator workflow
1. Open the connected Google Sheet.
2. Filter by status, industry, or submitted_at.
3. Review the recommendation_text and additional_context columns.
4. Use the inquiry ID and brief code when preparing your response.
